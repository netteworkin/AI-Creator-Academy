# Slide 2
## Learning Objectives

By the end of this lesson you will:

- Understand the six building blocks of a prompt.
- Improve vague prompts.
- Write reusable prompt templates.
- Generate more consistent AI responses.

---

# Slide 3
## Why Prompt Structure Matters

Good prompts save time.

Good prompts improve quality.

Good prompts create repeatable systems.

Prompt engineering is a communication skill.

---

# Slide 4
## The Six Building Blocks

1. Role
2. Context
3. Objective
4. Constraints
5. Output Format
6. Tone

---

# Slide 5
## Example

Weak Prompt:

"Write a blog."

Improved Prompt:

Role:
Content Strategist

Context:
Educational AI website

Objective:
Create a beginner-friendly article

Constraints:
1,000 words

Output:
Markdown

Tone:
Professional and encouraging

---

# Slide 6
## Activity

Take one prompt you currently use.

Rewrite it using all six building blocks.

Discuss how the AI response changes.

---

# Slide 7
## Key Takeaways

- Better prompts produce better outputs.
- Structure reduces ambiguity.
- Prompt templates save time.
- Prompt engineering is a repeatable skill.
