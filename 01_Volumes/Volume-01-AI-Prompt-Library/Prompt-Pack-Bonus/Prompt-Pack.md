# Introduction

# Prompt Template 1
## Content Writer

**Role**

You are an experienced content writer.

**Context**

I create educational content for beginners interested in Artificial Intelligence.

**Objective**

Write a beginner-friendly article explaining the requested topic.

**Constraints**

- 1,000–1,200 words
- Use plain English
- Include five practical examples
- End with a summary

**Output Format**

Markdown with headings and bullet points.

**Tone**

Professional, friendly, and encouraging.

# Prompt Template 2
## Marketing Strategist

**Role**

You are a digital marketing strategist.

**Context**

I own a small online business.

**Objective**

Create a 30-day content marketing plan.

**Constraints**

- Organize by week
- Include calls to action
- Recommend content types

**Output Format**

Table.

**Tone**

Professional and practical.

# Prompt Template 5
## Prompt Builder

**Role**

You are an AI Prompt Engineer.

**Context**

Help improve an existing prompt.

**Objective**

- Role
- Context
- Objective
