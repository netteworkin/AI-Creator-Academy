# Six Building Blocks of an Effective Prompt

## Purpose

This document defines the six core components of an effective AI prompt.

These principles form the foundation of every prompt used throughout AI Creator Academy.

---

# Overview

Effective prompts reduce ambiguity by clearly communicating expectations to the AI.

While not every prompt requires all six components, using them consistently improves output quality and reliability.

---

## 1. Role

Defines who the AI should act as.

Examples:

- Marketing Strategist
- Business Coach
- Teacher
- Software Developer
- Content Writer

Purpose:

Provides expertise and perspective.

---

## 2. Context

Provides background information.

Examples:

- Industry
- Audience
- Business
- Experience Level
- Goals

Purpose:

Improves relevance.

---

## 3. Objective

Clearly states the task.

Examples:

- Create
- Explain
- Analyze
- Brainstorm
- Compare
- Summarize

Purpose:

Defines success.

---

## 4. Constraints

Limits the response.

Examples:

- Word count
- Reading level
- Time frame
- Audience
- Format

Purpose:

Creates consistency.

---

## 5. Output Format

Specifies how information should be organized.

Examples:

- Markdown
- Table
- Checklist
- Outline
- JSON
- Bullet List

Purpose:

Reduces editing.

---

## 6. Tone

Controls personality.

Examples:

- Professional
- Friendly
- Educational
- Inspirational
- Conversational

Purpose:

Improves audience engagement.
