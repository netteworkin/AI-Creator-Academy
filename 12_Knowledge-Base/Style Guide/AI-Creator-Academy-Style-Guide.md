# AI Creator Academy™ Style Guide

## Purpose

This document defines the writing, formatting, branding, and instructional standards for every product created within AI Creator Academy™.

The goal is to ensure every volume, workbook, prompt pack, presentation, and future product provides a consistent learning experience.

---

# Mission

Help beginners confidently use Artificial Intelligence to create, learn, build businesses, and solve real-world problems through practical education.

---

# Target Audience

- Beginners
- Entrepreneurs
- Content Creators
- Freelancers
- Educators
- Coaches
- Small Business Owners

Assume no technical background unless stated otherwise.

---

# Writing Principles

Every lesson should be:

- Clear
- Practical
- Actionable
- Encouraging
- Beginner-friendly

Avoid unnecessary jargon.

When technical terms are introduced, define them in plain language.

---

# Voice

Write like an experienced mentor.

Be confident without sounding arrogant.

Teach rather than impress.

Encourage experimentation.

Respect the reader's intelligence.

---

# Tone

Professional

Friendly

Supportive

Educational

Positive

Never sarcastic.

Never dismissive.

---

# Chapter Structure

Every chapter should include:

1. Learning Objectives
2. Introduction
3. Main Lesson
4. Practical Examples
5. Real-World Applications
6. Key Takeaways
7. Chapter Summary

---

# Workbook Standards

Every workbook should include:

- Review Questions
- Practice Exercises
- Reflection
- Challenge Activity

Learning should reinforce—not repeat—the manuscript.

---

# Prompt Pack Standards

Every prompt should include:

- Role
- Context
- Objective
- Constraints
- Output Format
- Tone

Whenever practical, include a short explanation of why the prompt works.

---

# Presentation Standards

Slides should:

- Focus on one idea at a time
- Use concise bullet points
- Support discussion rather than replace it
- End with an activity or reflection

---

# Formatting Standards

Use Markdown headings consistently.

Use numbered lists for sequences.

Use bullet lists for collections.

Keep paragraphs short.

Highlight key ideas clearly.

---

# Naming Conventions

Use descriptive file names.

Maintain consistent folder structures across all volumes.

Avoid duplicate names.

---

# Quality Checklist

Before publishing, verify: 

- Content is accurate.
- Language is beginner-friendly.
- Examples are practical.
- Exercises reinforce learning.
- Formatting is consistent.
- Grammar and spelling are correct.

---

# Guiding Principle

Every product should help learners become confident creators, not just consumers of AI.
